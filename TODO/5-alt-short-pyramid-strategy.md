# Шорт альтов по нисходящему тренду с пирамидингом

Статус: исследование завершено (2026-10-11), в live-сервис не перенесена.

## Идея

Альты падают ровнее, чем растут. Входим в шорт на развороте 15m, когда монета
в нисходящем тренде 4H; пока цена идёт в нашу сторону — быстро добираем
позицию, дальше ведём широким трейлингом до разворота. Прибыль дают редкие
длинные падения; сделки, выбитые стопом сразу, мелкие и в минусе.

## Точка входа (по закрытым свечам)

| Условие | ТФ | Правило |
|---|---|---|
| Режим | 4H | close < EMA200 **и** EMA50 < EMA200 |
| Триггер | 15m | Supertrend(10, 3) развернулся вниз на закрытии свечи |
| Вход | 15m | шорт по рынку по close этой свечи |

Пока по монете открыта позиция — новые сигналы по ней игнорируются.

## Сопровождение (конфиг пирамидинг-бота)

| Параметр | Значение |
|---|---|
| `bot_type` | pyramiding |
| `order_count` | 4 (вход + 3 добора) |
| `pyramiding_multiplier` | 1.0 — все ордера одного размера |
| `step_percent` | 0.5% от предыдущего ордера |
| `sl_initial` | 2% от цены входа (ордера 1–2) |
| `sl_breakeven_on_order2` | выкл |
| `sl_after_order3` | 2% от средней |
| `use_trailing` / `trailing_percent` | вкл / **1U** монеты, стоп только опускается |
| `tp_percent` | нет — выход только по стопу/трейлингу |

**U** — медианный дневной диапазон (high−low)/close монеты (считался на
01.2021–06.2024). Трейлинг 1U: BTC 4.1%, ETH 5.0%, XRP 5.7%, DOGE 6.4%,
ARB 6.1%, LINK 6.9%, APT 7.0%, SUI 7.8%, AVAX 8.0%, SOL 8.1%, OP 8.2%,
FET 8.4%, INJ 8.5%, NEAR 8.8%, TIA 10.1%, 1000PEPE 10.2%, WIF 15.3%.

## Что проверено и отброшено

- Вход после отката 1H к EMA20/50 — не лучше входа без отката.
- Лонги по тем же правилам — в минусе почти каждый год.
- Фильтр по режиму BTC — ухудшает.
- Выбор «слабейших к BTC» при нехватке слотов — не лучше «по порядку».
- Шаг в единицах волатильности — хуже фиксированного; 0.5–0.75% лучше 1–3%.
- Фиксированный трейлинг для всех монет (2%, 3%) — хуже трейлинга в U.
- Трейлинг: плато 1–1.5U, 2U хуже. Лимит 8 позиций лучше 3/5/без лимита.

## Не проверено / что нужно для запуска

- Проскальзывание: вживую входы и доборы по рынку на тике, при шаге 0.5% это существенно.
- Funding: в симуляции шорт его только получает.
- В live-боте нет режима 4H, триггера Supertrend 15m и трейлинга в U.

Скрипты (локальные, не в git): `services/backtester/research/trend_pullback_pyramid.py`,
`services/backtester/research/short_portfolio.py`.
